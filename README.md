# Hey, I'm Fahriel 👋

I'm an Information Systems student at **Universitas Mulawarman (FT Unmul)** in Samarinda, Indonesia. Most of the projects on my GitHub start the same way: I run into something inconvenient on my own machine or network, and I end up writing a tool to solve it.

I like building software that stays out of the way and does its job well. Some days that means working close to the OS on Windows network packet routing in C#, other days it means putting together a lightweight desktop media trimmer in Python, building AI-powered web apps in TypeScript, or digging into datasets with Jupyter notebooks.

## What I've Been Building

**[WireShift](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FFarerudesu%2FWireShift)** (`C#` · `WinDivert`)  
A Windows utility that binds specific applications to specific network interfaces—like routing one app through Wi-Fi or a VPN while keeping everything else on Ethernet. Built with WinDivert for transparent packet-level routing without needing complex virtual machines or proxy chains.

**[EzTrimr](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FFarerudesu%2FEzTrimr)** (`Python` · `FFmpeg`)  
A straightforward, no-nonsense video and audio editor. I built this for quick, lossless media cuts without waiting for a heavy timeline editor to load.

**[vibetrip-ai-trip-curation](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FFarerudesu%2Fvibetrip-ai-trip-curation)** (`TypeScript`)  
An AI-assisted travel curation web app that helps put together personalized trip itineraries based on the kind of atmosphere and pace you're looking for.

**[isp-load-balance](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FFarerudesu%2Fisp-load-balance)** (`JavaScript`)  
A networking project focused on distributing traffic across multiple ISP connections to keep bandwidth stable when one line drops or slows down.
